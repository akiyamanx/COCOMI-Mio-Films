# 蒼龍、空へ。 — 初回3DCG試作

霧と岩の谷から、青緑の龍が体をうねらせて昇る8秒のオリジナルCGです。

- [動画 MP4](Mio_Dragon_Ascension.mp4) — 1280×720、24fps、192フレーム、H.264＋AAC。
- [Blender制作データ・スクリプト ZIP](Mio_Dragon_Ascension_Source.zip) — 完成シーン、制作工程のPython、合成音、動画化スクリプト、日本語説明。

動画はダウンロードして再生できます。最初は音量を小さめにしてください。

## この版について

リアルさを目指した最初の様式的なCG試作であり、映画の実写合成級の写実性を達成したものではありません。鑑賞時に「拡大すると首と胴のつながりがずれて見える」との指摘があります。実際の原因は未検証で、このアーカイブでは修正・再描画をしていません。

MP4は初回納品版そのままです。公開用ZIPは元の制作データからコピーし、Blender内の制作環境の絶対パスを相対パスに整理しました。モデル・アニメーションは変更していません。ZIP内のREADMEにも既知の課題を追記しています。

Blender 4.3.2で制作。完成シーンを開くだけなら同梱スクリプトの実行は不要です。再描画にはBlender、音の生成にはPython＋NumPy、動画化にはffmpegが必要です。手順はZIP内のREADME_JA.txtを参照してください。制作工程のスクリプトは出力ファイルを上書きするため、作業用コピーで利用してください。
