# COCOMI Mio Films

澪 / Mio がコードで描く、COCOMIのオープニングと動く紙芝居の作品集。
HTML作品の映像はCanvas、音楽はWeb Audioによるオリジナル合成音で構成しています。Blenderによる3DCG試作も収録しています。

## 作品

- [水の記憶](COCOMICore_Mio_Opening.html) — 34秒。水の波紋と二つの光が、静かな印へと結ばれるオープニング。
- [ひと粒の、とびら。](COCOMICore_Mio_Story_Opening.html) — 48秒。小さな紙の配達人が植えた種は、芽を伸ばし、光の扉になります。
- [きょう、世界にひとつのキラン。](COCOMICore_Mio_Sparkle_Opening.html) — 32秒。レモン色の小さな子が、明るい朝に色と光を届けます。
- [ひとりぶんの余白](COCOMICore_01_Hitoribun_no_Yohaku.html) — 90秒。『ひと粒の、とびら。』短編集・第一話。冬の水辺で、隣にひとりぶんの席を空ける、小さな物語。詩の言葉を添えた改訂版。
- [雨の、つづき。](COCOMICore_02_Ame_no_Tsuzuki.html) — 88秒。『ひと粒の、とびら。』短編集・第二話。同じ世界の青い紙の人が、受け取った傘を次の人と分け合います。雨の帰り道に4つの短い詩を添えた作品。

## 連作紙芝居『ふたりの余白』

- [きのうの、つづき。](COCOMICore_Futari_01_Kinou_no_Tsuzuki.html) — 自動上映96秒・3枚。『ひとりぶんの余白』でベンチに座った二人の、昨夜の別れ際から翌日の再会へ続く物語です。

自動上映のほか、「自動でめくる」をオフにして一枚ずつ読むこともできます。「前の絵」「次の絵」で場面を移動できます。台詞は文字で表示し、音声読み上げはありません。

『雨の、つづき。』は別の短編集の一篇です。この連作は、ベンチの二人の物語を直接引き継ぎます。

## 観かた

HTMLファイルをダウンロードし、JavaScriptが使えるブラウザで開いてください。GitHub上のファイル表示はソース閲覧用で、その場で上映するページではありません。

音は再生ボタンを押してから鳴ります。最初は音量を小さめにしてください。音なし再生も選べます。外部素材・ライブラリ・フォントのダウンロードや外部通信は使いません。表示や音色は端末・ブラウザにより異なります。
